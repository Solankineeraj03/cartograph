How to start the live backend (needs the GPU host)

The model runs on one RTX 3090. Start it from your laptop with an SSH tunnel; the page talks to localhost:8012, which the tunnel forwards to the GPU host. Closing the SSH session (or Ctrl-C) shuts everything down.

ssh -L 8012:127.0.0.1:8012 <gpu-host> 'bash ~/cartograph/repo/scripts/demo_up.sh'

Startup takes 1–2 minutes (feature materialization into Redis, then vLLM loading). The script refuses to start if another job is using the GPU. When the backend is off, this page replays real recorded responses instead.

Supported product types: keyboard, mouse, keyboard mouse combo, mouse pad, headphones, microphone, webcam, monitor, laptop stand, USB hub, speaker, charger. Include a budget like “under $100”.
